# madare-emrooz

Backend and staff web panel of Madare Emrooz (مادر امروز), a maternal and child health platform.

| Folder | What it is |
|---|---|
| [`backend/`](backend/README.md) | Flask + PostgreSQL API used by the mobile app and the web panel. Postman collection in `backend/docs/postman/`. |
| [`web-panel/`](web-panel/README.md) | Vue 3 + daisyUI web panel for midwives, doctors and admins, in Persian and English. |

The mothers' mobile app lives in its own repository.
